## 5 实现要点

### 5.1 对话与草案

- 对话消息只产生「建议」；作者点「应用建议」才走 `blueprint.propose_patch`。
- Agent 消息底部标「仅讨论」或「用于草案」，避免误以为已改文件。
- 停止后保留已生成文本；重试只重跑当前消息。

### 5.2 角色卡与 voice

- 必填：身份、外貌、句长倾向、口头禅、称呼习惯、禁用词、欲望、恐惧、禁忌、初始关系、初始已知/未知。
- `character_id` 稳定；改卡产生 `card_version`，不换 ID。
- 改卡要列出受影响章节与记忆条目（M0 至少给章节列表，不做影响分析）。

### 5.3 G1 与建库

```
G1 确认
  → 校验：覆盖检查无阻断、voice 四项齐全、至少 1 主线/1 卷/1 章
  → 写 gate_record(G1)
  → roster.propose（角色清单 + 初始事实）
  → memory.namespace.create（5 私有 + 1 公共）
  → 隔离自检：每个角色探针只能命中自己
  → setup_state=complete；蓝图锁定
```

- 建库失败不回滚蓝图，项目标 `setup_incomplete`，创作台禁用，横幅可重试。
- `memory.namespace.create` 幂等：重复调用返回原命名空间；`isolation_verified` 写项目元数据。

### 5.4 覆盖检查占位

- M0 只显示「未启用（P1）」；不阻断 G1。
- 数据契约先留：`coverage.check` manifest 存在，`enabled=false`。

## 7 风险与回退

| 风险 | 触发 | 回退 |
|---|---|---|
| 蓝图编辑器范围蔓延 | 想做成完整大纲工具 | 只做字段 + 树；拖拽排序可后置 |
| 规划 Agent schema 不稳定 | 提案 JSON 解析失败 | 降级为纯文本 + 作者手动填；不阻塞 G1 |
| 建库半失败 | 部分命名空间已建 | 幂等重试；`setup_state` 明确，不假装完成 |
| 角色卡字段过多 | 作者填不完 | M0 只强制 voice 四项 + 身份/欲望/恐惧/禁忌 |

## 8 进入下一阶段的条件

1. G1 可重复执行，建库幂等。
2. 隔离自检通过，跨角色检索为空。
3. 蓝图 G1 后只读，修改只能走提案。
4. `setup_incomplete` 的禁用与重试路径演练过。
5. 规划对话停止/重试不产生孤儿消息。
