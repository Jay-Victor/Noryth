# M2 质量基线：声音区分度与伏笔回收率

> 阶段 19（M2-1）交付；对应 PRD §10 第 3 条退出标准 / DEV-PLAN §16.5。
> 数字来自 `scripts/calibrate-voice.mjs`（语料）与 `scripts/m2-baseline.mjs`（项目，只读）。
> 本文件只记录口径与结果，不自动生成；换语料或阈值版本必须同时更新本文件。

## 1 方法

| 项 | 口径 |
|---|---|
| 指标 | 句长 √JSD（55%）+ 口头禅率差（15%）+ 问句率差（15%）+ 第一人称率差（15%），clamp 0–1 |
| 取样 | 只读 revision 清单：定稿章读 `final_revision_id`，其余读 `current_revision_id`；只统计 `speaker_type='character'` 且有正文的拍 |
| 场景汇总 | 两两区分度取**最低一对**；句长 JSD 与三个比率取各对平均（旧四字段语义不变） |
| 不足数据 | 在场角色少于 2 人或某角色少于 2 拍 → `pairs=[]`、`insufficientData=true`；0 不代表「很区分」 |
| 阈值 | `zh-v1` / `distinctnessMin = 0.252`（`src/shared/domain/voice.ts`） |
| 伏笔回收率 | `closed / (open + closed)`，只读 `foreshadow`；超期 = 未回收且计划回收章 ≤ 当前最大章序 |
| 复跑 | `node scripts/calibrate-voice.mjs`、`node scripts/m2-baseline.mjs <项目目录>` |

「同一人」与「不同人」的分界很窄，这是**夹具**的特性，不是真实小说的普遍结论（见 §4）。

## 4 局限

- 语料是合成夹具：句长分布比真实小说集中，绝对阈值不能直接外推到所有作者；0.252 是起点。
- 指标只看句法表面（句长、口头禅、问句、第一人称），不看语义；两个人可能「用词完全不同
  但句法同构」而被判低分，也可能「句法差很大但语气相同」而被判高分。
- 旁白不参与两两区分度（可单独作为场景参考，但当前未进契约）。
- 伏笔回收率只覆盖 M1 的作者手写标注；自动识别是 M2 之后的范围。
- 项目基线的 `sameCharacterFalseAlarm` / `differentCharacterDetection` 是语料级指标，
  不是某个项目的准确率；`scripts/m2-baseline.mjs` 的输出已显式标注 `calibration.note`。
- 换语料或改公式必须升 `VOICE_THRESHOLD.version` 并重跑校准；历史 `voice_metric` 按
  `threshold_version` 自动重算（同一 scene + revision 覆盖，不追加历史）。
