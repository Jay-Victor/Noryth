# Noryth 页面设计文档（UI Spec）

> 版本 v0.4 ｜ 状态：设计草案 ｜ 配套 PRD v0.6 ｜ 范围：M0 六页（首页 / 规划台 / 创作台 / 审批台 / 记忆台 / 设置中心）
>
> 形态：Electron 桌面端，Windows 10/11 x64 首发 ｜ 单位：CSS px（100% 缩放）

**本文补什么**：PRD 定义了 Agent 边界、工具层、闸门与数据模型，但没有定义界面形态。本文把六个页面落成可开工的布局、分区、组件、状态与键盘路径。布局数字由 `docs/scripts/check_ui_spec.py` 计算，线框图见 `docs/assets/wireframes.html`。

**不覆盖**：视觉稿与品牌资产、图标绘制、动效曲线、文案本地化、原生菜单与托盘、高对比主题实测。

**阅读指引**：只看三节 —— §2.2（四分区折叠规则，唯一能在写代码前证伪布局的一节）、§5.4（逐拍确认条，最高频操作）、§9.1（闸门行动条，决定权限是否真的落在界面上）。

## 1 范围与基线

### 1.1 六个页面与它们的闸门

| 页面 | PRD 落点 | 打开时机 | 主闸门 | 唯一主操作 | 写入边界 |
|---|---|---|---|---|---|
| 首页 | PRD 5.5 节 | 启动；无项目打开 | G0 | 新建项目 / 打开项目 | 只创建与打开项目，不写内容 |
| 规划台 | PRD 5.1 节 | 项目打开后的默认页 | G1 | 确认蓝图 | 蓝图草案、角色卡草案（经控制器） |
| 创作台 | PRD 5.2 节 | 蓝图已确认 | G2 / G3 | 确认当前拍 | 正文草稿（经文档控制器） |
| 审批台 | PRD 5.3 节 | 章节 draft_complete | G4 / G5 / G6 | 授权修订 / 定稿 | patch 提案；定稿按钮唯一位置 |
| 记忆台 | PRD 5.4 节 | 章节 finalized | G7 | 应用固化 | 记忆、世界状态、关系图（确认后） |
| 设置中心 | PRD 5.6 节 | 任意时刻，独立窗口 | — | 保存并测试 | API Key、绑定、偏好 |

- 未过 G1：创作台、审批台、记忆台在导航上置灰；直接访问显示阻塞说明，不显示空界面。
- 未 draft_complete：审批台不出现该章；未 finalized：记忆台不出现固化任务。
- 定稿按钮只存在于审批台预览区 header；创作台与记忆台不提供，命令面板里的定稿必须走同一个确认对话框。

### 1.2 窗口、栅格与断点

- 主窗口默认 1440×900；最小 1280×800；最大化不限。
- 设置独立窗口默认 1040×720；最小 880×600；不随主窗口缩放。
- 标题栏 40（自绘，右侧系统按钮），状态栏 24；内容区高度 = 窗口高 − 64。
- 基准 4px；间距 4 / 8 / 12 / 16 / 24 / 32；圆角 6（控件）/ 8（卡片）/ 10（窗口）；分隔线 1px。
- 层级只用「底色差 + 1px 线 + 圆角」，不用投影堆叠；只有模态与抽屉有投影。
- 可变栅最多 3 个（PRD 的规则）；第四块内容要么固定宽，要么折叠。§2.2 是这条规则的落实。

### 1.3 排版与视觉基线

| 元素 | 规格 | 说明 |
|---|---|---|
| 正文 | 15px / 1.8，思源宋体 | 预览区正文与导出预览；目标 32–42 字/行 |
| 界面 | 12px / 1.5，Segoe UI Variable + 微软雅黑 | 列表、表单、状态 |
| 辅助 | 10.5px / 1.5 | 元信息、来源、路径 |
| 标题 | 15px / 600 | 页面与卡片标题；首页字标 52px / 650，主张 17px / 600 |
| 等宽 | 11px / 1.5，Consolas | 路径、revision、job id、beat id |
| 图标 | 16 / 20，1.4 stroke | 线性；不用彩色图标表达状态 |
| 主题 | 亮 / 暗 / 跟随系统 + 强调色 | 只允许语义 token；组件不写死颜色 |

- 颜色只走 token：`--bg`、`--card`、`--fg`、`--muted`、`--border`、`--accent`、`--danger`、`--warn`、`--ok`。
- 状态不能只靠颜色：阻断用「图标 + 文字」，只读用锁图标 + 文案，stale 用虚线徽标。
- 正文列上限 630px，宽屏加边距不加行长；1600px 时预览 583px、列宽 519px（34.6 字/行）。

### 1.4 交互与无障碍基线

- 键盘优先：确认、重生成、编辑、切拍、切 tab、开关树都有快捷键（§9.7）。
- 焦点环 2px accent + 1px offset；抽屉打开后焦点进入抽屉，Esc 关闭并回到触发元素。
- 流式输出不做逐字动画；只在段落完成时淡入 120ms，避免布局抖动。
- 确认 / 重生成不弹二次确认（PRD 5.2）；破坏性、不可逆、花钱三类必须确认。
- 200% 缩放不截断按钮；面板改为滚动，最小点击区 28×28。
- 屏幕阅读器：拍卡 `role=article`，`aria-label="第 12 拍，沈昼"`；流式区 `aria-live=polite`，只在拍完成时播报，不逐 token 播报。

## 2 工作台外壳

四个工作台（规划 / 创作 / 审批 / 记忆）共用一个外壳：56px 导航 + 四分区 + 状态栏。差异只在四区内容与底部行动条。

### 2.1 左侧导航

- 56px 固定；自上而下：首页、规划、创作、审批、记忆、弹性空白、设置。
- 每项 48×44：20px 图标 + 9px 标签；当前项 accent 12% 底，文字转前景色。
- 角标：创作 = 待确认拍数，审批 = 待审章节数，记忆 = 待固化任务数；超过 99 显示 99+。
- 闸门禁用：未过 G1 时「创作 / 审批 / 记忆」置灰，hover 显示原因（「先完成 G1 蓝图确认」）；点击弹一条说明，不静默。
- 首页与设置始终可用；无项目打开时导航仍显示，规划 / 创作 / 审批 / 记忆置灰。

### 2.2 四分区与折叠规则

四分区：**会话列表**（在哪一章、哪一次对话）、**对话聊天**（与哪个 Agent 说）、**文件预览**（看什么、改什么）、**文件树**（项目还有什么）。

| 视口 | 模式 | 导航 | 会话列表 | 对话 | 文件预览 | 文件树 | 正文列 | 字/行 |
|---:|---|---:|---:|---:|---:|---:|---:|---:|
| 1280 | W3 | 56 | 64 | 505.9 | 607.1 | 44（轨道） | 543 | 36.2 |
| 1360 | W2 | 56 | 248 | 458.6 | 550.4 | 44（轨道） | 486 | 32.4 |
| 1440 | W2 | 56 | 248 | 495.0 | 594.0 | 44（轨道） | 530 | 35.3 |
| 1600 | W1 | 56 | 248 | 485.9 | 583.1 | 224 | 519 | 34.6 |
| 1920 | W1 | 56 | 248 | 631.4 | 757.6 | 224 | 630 | 42.0 |
| 2560 | W1 | 56 | 248 | 922.3 | 1106.7 | 224 | 630 | 42.0 |

- W1 ≥1600：四栅并列；文件树 224，可拖到 300。打开文件树会让对话从 495 回落到 485.9，这是四栅的代价；作者可拖窄树或 Ctrl+B 收起。
- W2 1360–1599：文件树收为 44px 轨道（5 个根节点 + 快速定位），点击展开 320px 抽屉；抽屉是临时选择器，选中文件即关闭，不允许常驻。
- W3 1280–1359：会话列表再收为 64px 轨道（只留状态点与计数），对话与预览保持可读。
- 拖拽：会话 224–320，树 200–300；宽度写入项目级 UI 状态，不写进 `noryth.db`。
- 折叠优先级：窗口变窄先收树，再收会话；对话与预览永不折叠。
- 标题栏与状态栏不参与栅格；预览区内部的二级分栏（报告左问题右维度、分镜表头固定）不计入栅格数量，宽度不超过预览区。

为什么 1440 不做四栅：同视口强行并列（会话 248 + 树 224）后，对话 413.2、预览 495.8、正文列 431.8px，只有 28.8 字/行，低于 32 字下限（脚本断言）。收起树后正文列 530px、35.3 字/行；这是「四分区」与「可读正文」的唯一交集，也是 PRD 4.1 节反对四栏并列的量化依据。

### 2.3 分区职责矩阵

| 分区 | 规划台 | 创作台 | 审批台 | 记忆台 |
|---|---|---|---|---|
| 会话列表 | 规划会话 + G1 未决项 | 卷 / 章 + 场景进度 + 本章会话 | 待审章节 + 轮次 R1–R3 | 固化任务 + 历史 + 维护 |
| 对话 | 规划 Agent | 编排 Agent + 执行流 | 审批 Agent | 记忆管理 Agent |
| 文件预览 | 蓝图、角色卡、世界观、覆盖检查 | 正文、分镜、章纲 | 初稿、报告、差异、版本 | 提案、角色记忆、世界状态、关系图、审计 |
| 文件树 | 项目结构 + 数据库视图 | 同左 | 同左 | 同左 |

### 2.4 跨区联动

| 触发 | 结果 | 约束 |
|---|---|---|
| 点对话中的文件 chip | 预览区切换文件并高亮引用段落 | 不新开窗口；一次只显示一个文档 |
| 预览中选中文字 | 浮动条「引用到对话」 | 只插入引用 chip，不复制全文 |
| 点树中文件 | 预览区加 tab 并切换 | 不关闭对话；不改变对话滚动位置 |
| 拍卡「依据」 | 预览区内展开依据面板 | 不新增第五栅；面板 320 |
| 审批问题「定位」 | 切到初稿并滚动到 beat | 高亮 3 秒，不选中文字 |
| 记忆提案的来源 | 打开对应定稿段落（只读） | 不向非作者角色展示私有记忆原文 |

- 对话与预览的滚动不同步：作者常要一边看旧段落一边讨论，同步滚动会抢焦点。
- 预览区 tab 最多 6 个，超出先进先出；章节正文 tab 不可关闭。

### 2.5 状态栏、命令面板与通知

- 状态栏 24px：左「已保存 10:43 · rev_012」；中「只读 / 蓝图未确认 / 等待确认」；右「章预算 ¥0.84 / ¥5.00 · DeepSeek V3 · 在线」。
- 保存状态三态：保存中（spin）、已保存（时间）、保存失败（红字 + 重试）。
- Ctrl K 命令面板：新建 / 打开项目、切页、切 tab、开演、确认当前拍、送审、定稿、打开设置。定稿命令必须走与按钮相同的确认对话框，且没有单击快捷键。
- 通知：右下 toast，最多 3 条；同一事件不重复；点击跳到对应拍 / 章节 / 任务。

### 2.6 浮层、抽屉与只读态

| 浮层 | 宽度 | 触发 | 关闭 | 是否遮正文 |
|---|---:|---|---|---|
| 文件树抽屉（W2 / W3） | 320 | 点 44px 轨道 | 选中文件 / Esc | 临时遮，选中即关 |
| 上下文检查器 | 420 | 拍卡「上下文」 | Esc / 点外部 | 不遮正文：≥1600 占用对话栅，<1600 模态并置顶当前拍 |
| 依据面板 | 320 | 拍卡「依据」 | Esc | 预览区内展开，不遮当前段 |
| 确认对话框 | 480 | 闸门 / 破坏性操作 | 取消 / Esc | 遮罩，必须显式选择 |
| 新建项目向导 | 640 | 首页 | 取消 / Esc | 遮罩，三步可后退 |

- 抽屉是选择器，不承担解释；解释型浮层（依据面板、上下文检查器）一律不覆盖正文。检查器占用对话栅，关闭后恢复对话与滚动位置。
- 只读锁：第二个窗口顶部 32px 常驻横幅「此项目已在另一窗口打开，当前为只读」，所有写入按钮禁用；状态栏显示锁持有窗口。
- 离线：生成、审批、记忆抽取禁用并显示原因；本地编辑、浏览、导出、G7 应用（本地嵌入）可用。
- 所有禁用按钮必须有 `title` 或相邻说明，不能只灰掉。

## 3 首页（项目管理）

### 3.1 布局与视觉重心

```
┌ 标题栏 40 ─────────────────────────────────────────────────┐
│ N 项目库                              Ctrl K   —   □   ×    │
├────┬───────────────────────────────────┬───────────────────┤
│ 56 │ NORYTH ｜ 剧场式小说工作台  本地优先│ 从零开始           │
│ 导 │                                   │ 1 选空文件夹       │
│ 航 │ Noryth  [N]                       │ 2 蓝图 G1          │
│    │ ────────                          │ 3 开演第一场       │
│    │ 把小说演一遍，再把它写下来。       │                   │
│    │ 角色各自只知道自己该知道的事。     ├───────────────────┤
│    │ 每一句台词都能追问为什么。         │ 工坊               │
│    │                                   │ 项目 3             │
│    │ 01 启动 ───────────────────        │ 累计字数 210,580   │
│    │  打开项目                       →  │ 已定稿章节 15      │
│    │  新建项目                       →  ├───────────────────┤
│    │                                   │ 开工之前           │
│    │ 02 全部项目 3    按最近打开排序    │ 分支 每一拍        │
│    │  黑漆匣子 …        3/24 章 2 小时  │ 文件 库与 Git      │

│    │  未命名项目 …      路径不可用 3 天  │                   │
├────┴───────────────────────────────────┴───────────────────┤
│ 状态栏 24                                                   │
└─────────────────────────────────────────────────────────────┘
```

- 两栏：左 1fr（最小 720），右 298，间距 26；内容最大 1120 居中；首页也显示 56px 导航（首页 active，其余在无项目时置灰）。
- 左列四段：品牌头（logo + NORYTH + 本地优先）、大字标与主张、01 启动、02 全部项目。
- 右列三块：从零开始（虚线卡，三步说明 + 指回启动区的文字，不放入口按钮）、工坊（项目 / 累计字数 / 已定稿章节）、开工之前（分支 / 文件）。
- 大字标是记忆点，但不是入口；真正的入口是「01 启动」两行与「02 全部项目」列表。
- 同一动作只出现一次：新建项目只在 01；Ctrl K 只在标题栏；设置只在左侧导航；页名是「项目库」，列表叫「全部项目」；回退只在右栏提示里解释。
- 1280 下仍为两栏（左 744 / 右 298）；1280 是最小窗口，硬下限，不做单列折叠。
- 空库时 02 只显示一张空态卡，文案指回 01 启动，不再放第二个新建按钮。

### 3.2 全部项目列表

| 区域 | 内容 | 规则 |
|---|---|---|
| 状态点 | 6px 实心 / 空心 | 进行中实心；只读或路径缺失空心 |
| 名称行 | 项目名 11.5 / 600 + 徽标 | 徽标：进行中 / 只读 · 已开窗 / 路径不可用 / 初始化未完成 / 需更新 |
| 简介 | 10.5 / 400 单行 | 超出省略 |
| 路径 | 9 等宽单行 | 中间省略，保留盘符与末级目录 |
| 元信息 | 章数 · 字数 | 右对齐；只算已定稿 |
| 时间 | 最近打开 | 相对时间；右对齐 |
| 菜单 | 「···」 | 在文件夹中查看 / 从列表移除 / 重新定位 |

- 行高 64（上下 10 + 三行文本约 43 + 1px 分割线）；hover 底色 fill；整行可点。
- 为什么从卡片改列表：项目会增长到几十个，列表可扫读、可排序、路径只截一次；卡片留给右列「从零开始」。
- 列表不提供新建入口：新建属于 01 启动，避免同一动作在页面上出现两次。
- 进度只算已定稿字数，草稿不计；没有目标篇幅时不显示百分比。
- 工坊三项同口径：项目数、累计定稿字数、已定稿章节；草稿不计，避免首页数字比实际进度乐观。
- 排序：最近打开倒序，默认不分组；超过 20 个项目时顶部出现过滤框（P1）。
- 打开：双击或 Enter；选中态 accent 8%；打开后回到上次未确认的拍，列表第一行就是回访入口，不另设「继续上次」区块。
- 移除只影响列表，不删磁盘；toast 明说「文件没有动」，并提供 5 秒撤销。

| 状态 | 表现 | 可用操作 |
|---|---|---|
| 正常 | 实心点 + 章数 + 字数 | 打开、移除、在文件夹中查看 |
| 只读 | 空心点 +「只读 · 已开窗」 | 以只读打开、移除 |
| 路径缺失 | 空心点 +「路径不可用」 | 重新定位、移除 |
| 初始化未完成 | 「初始化未完成」 | 继续初始化、在文件夹中查看 |
| schema 更高 | 「需要更新应用」 | 只读打开、查看版本 |

### 3.3 新建项目（G0）

| 步骤 | 字段 | 校验 |
|---|---|---|
| 1 位置 | 父目录、文件夹名 | 空目录或可创建；写权限；路径 < 180 字符；磁盘 ≥ 200MB；同步盘给警告 |
| 2 作品 | 题材、目标篇幅、视角、内容边界 | 必填；篇幅给 10 万 / 30 万 / 自定义 |
| 3 确认 | 将创建的目录与文件 | 列出 noryth.db、manuscript/、assets/、exports/、backups/、schema v3 |

- 同步盘（OneDrive 等）警告理由要写清：SQLite WAL 与同步冲突会导致 `file_conflict`。
- 创建中显示逐项进度；失败回滚本次创建的目录（仅当为空或由本次创建）。
- 成功后直接进规划台并自动开一个规划会话，不让作者面对空界面。
- G0 决策写 `gate_record`：作者、时间、字段快照。

### 3.4 打开本地项目

- 入口接受 `noryth.db` 或项目文件夹；校验 schema_version、项目锁、最近备份。
- schema 高于应用：只读打开 + 提示升级；低于应用：先备份再迁移。
- 迁移失败不写库，保留备份路径与诊断信息。

### 3.5 状态与文案

| 状态 | 表现 | 文案 / 动作 |
|---|---|---|

## 4 规划台

### 4.1 布局

- 四分区按 §2.2；预览默认 tab「蓝图」；进入时焦点在对话输入框。
- 空项目：会话列表只有「立项」一条，预览显示空蓝图骨架（题材 / 篇幅 / 视角三个空字段 + 生成草案）。

### 4.2 会话列表区

- 分组：本项目会话（按更新时间）、G1 未决项、归档。
- 行高 32；状态点 6px（进行中实心 / 已归档空心）；未读点右侧；时间相对（今天 / 昨天 / 日期）。
- 未决项来自覆盖检查，点击切到预览「覆盖检查」并高亮该条。
- 新建会话默认标题「规划 · 第 N 次」；F2 重命名；删除需确认并保留归档（不物理删除）。

### 4.3 对话聊天区

- 对话按七步推进：题材 → 故事背景 → 核心创意 → 主线 → 分卷大纲 → 章节纲要 → 角色设定；每一步的产物落在预览区对应 tab，对话只负责讨论与修订。
- 消息类型：作者、规划 Agent、系统卡片（草案已生成 / 覆盖检查 / G1 结果）、流式占位。
- 消息最大宽 288；作者消息右对齐、accent 8% 底；Agent 消息左对齐、card 底。
- 每条 Agent 消息底部有「用于生成草案」或「仅讨论」标记，避免作者误以为对话直接改了文件。
- Composer：44–160 自适应；Ctrl+Enter 发送；@ 引用文件；草稿按会话本地保存。
- 停止 / 重试在消息头；模型 badge 显示当前绑定，点击跳设置。
- 不做：对话不能直接改文件；要改草案，用「应用建议」按钮走一次确认。

### 4.4 文件预览区

Tabs：蓝图 / 角色卡 / 世界观 / 覆盖检查（badge 数）。

| tab | 内容 | 交互 |
|---|---|---|
| 蓝图 | 左结构树 118 + 右字段：主线、卷纲、章纲 | 字段自动保存 800ms；结构树可拖排序 |
| 角色卡 | 身份 / 外貌 / voice / 欲望 / 恐惧 / 禁忌 / 初始关系 / 初始已知未知 | voice 四项必填；缺一项阻断 G1 |
| 世界观 | 条目列表 + 详情；visibility = public / secret | secret 条目标「仅作者与审批可见」 |
| 覆盖检查 | 4 类检查结果，通过项折叠 | 每条「定位」跳到对应章纲 / 角色卡 |

- 角色卡 voice 四项：句长倾向、口头禅、称呼习惯、禁用词；这是声音区分度的输入，不是文案建议。
- G1 前预览区是唯一可编辑区；G1 后蓝图只读，改蓝图走变更流程并触发影响分析。
- 预览区不显示 Agent 思考轨迹（规划阶段无 trace）。

### 4.5 文件树区

- 结构：蓝图 outline/、角色 characters/、世界 world/、稿件 manuscript/、导出 exports/；数据库视图节点（记忆库、世界状态）用虚线图标区分。

- 树是只读导航：新建 / 重命名 / 删除文件必须走控制器或对应编辑器，树里不提供写操作。

### 4.6 G1 确认

- 行动条固定在预览区底部：`G1 蓝图确认 · 3 项待办` + [影响预览] + [确认蓝图]。
- 有阻断时按钮禁用并显示第一条原因；点「影响预览」列出将注册的角色、库、世界初值。
- 确认对话框：将创建 5 个角色、5 个私有记忆库 + 1 个公共设定库、12 条世界初值；蓝图锁定 v1；确认后不可回退，只能走变更流程。
- 建库失败：项目标 `setup_incomplete`，创作台保持禁用，横幅提供重试；蓝图不回滚。

- 不做：未过 G1 就注册角色 / 建库；在规划台开演；允许对话直接写文件；把未确认草案标成「已保存」。

## 5 创作台

### 5.1 布局

```
┌ 章节 248 ─┬ 编排 / 执行流 486 ─┬ 正文 583 ────┬ 文件 224 ┐
│ 卷 / 章    │ 执行流拍列表        │ 拍锚点 + 正文 │ 稿件 / 分镜 │
│ 场景进度   │ 编排对话            │ 确认条 56     │ 视图节点    │
└───────────┴────────────────────┴──────────────┴───────────┘
```

- 进入时定位到上次未确认的拍；正文滚动到该拍，锚点高亮。
- 顶部 tab 默认「正文」；「分镜」有冲突时显示红点（配文字提示，不只靠颜色）。

### 5.2 会话列表区

- 章节树按卷分组；章行：标题 + 状态 chip（已规划 / 已分镜 / 进行中 / 待审批 / 已定稿 / 已暂停）。
- 章行下缩进显示「场景 2 / 3 · 拍 12 / 24」与微进度条。
- 本章会话：编排对话、重生成记录、拒演记录。
- 状态 chip 用文字，不只用颜色；「进行中」额外有实心点。

### 5.3 对话聊天区

- 顶部分段控件：编排对话 / 执行流。
- 执行流是只读日志：每拍一行（bt id、speaker、状态、字数、耗时）；点击滚动正文到该拍；不提供输入框。
- 编排对话：与编排 Agent 讨论章节要求、场次顺序、出口条件；只改分镜草案，不改正文。
- 分镜摘要卡：编排在对话里贴「3 场 24 拍 · 出口条件」，点开在预览区分镜 tab 查看完整表。
- 系统卡片：场次出口条件、角色拒演、预算预警、分镜耗尽。
- 拒演卡片：理由 + [改分镜] [改角色卡] [换角色]；不提供「强制继续」。
- Composer 同规划台；执行流模式下隐藏。

### 5.4 文件预览区与逐拍确认

**正文渲染**

- 连续正文，不按拍分块卡片；左侧 26px gutter 显示 `bt_012`，hover 出现拍卡入口。
- 正文按调度器拍序追加：新拍只落在文末或当前场景末尾，不重排已确认段落。
- 当前拍左侧 2px accent 线；已确认拍正常；stale 拍右上角虚线徽标；author_edited 拍显示「已手改」。
- 已确认的连续拍可折叠为「bt_001–bt_010 · 10 拍已确认 · 展开」。
- 流式：段末光标 + 「生成中 3.2s」；不逐字跳动，不改变其他拍位置。
- 正文列宽按 §2.2；15 / 1.8 宋体；段首缩进 2em。

**拍卡**

| 区域 | 内容 | 规则 |
|---|---|---|
| 头部 | 拍号、speaker、状态、字数、耗时 | sticky 在拍顶部 |
| 正文 | body | 只显示正文，不显示 trace |
| 依据 | chips（memory / belief / fact / canon / outline / manuscript） | 点开依据面板；不整段展开私有记忆 |
| 轨迹 | 折叠「思考与工具调用 3 步」 | 仅作者可见；不进入下一轮 |
| 元信息 | 模型、degraded、token | degraded 必显示原因（检索为空 / 上下文裁剪 / 模型降级） |

**逐拍确认条**（固定在预览区底部，56px）

| 元素 | 内容 | 规则 |
|---|---|---|
| 信息 | `拍 12/24 · 沈昼 · 78 字` | 左对齐；字数千分位 |
| 依据 | `依据 3` | 打开依据面板 |
| 上下文 | `上下文` | 打开检查器（在对话栅展开） |
| 重生成 | `重生成 Ctrl+R` | 旧版标 superseded，不删除 |
| 编辑 | `编辑 E` | 正文就地编辑；保存后标 author_edited |
| 确认 | `确认 ⏎` | 主按钮；确认后 150ms 内出现下一拍占位 |

- 确认后下游不自动重跑；若上游改过，下一拍标 stale 并给三选一。
- 连续确认不弹二次确认；提交被拒时行内提示并保留当前拍。
- `拍 12/24` 的 24 是本章拍数上限，不是剩余拍数；hover 显示「本场 7/12 拍」。

**重新生成与编辑**

- 重生成只重跑当前拍；连续重生成产生 superseded 链，不产生孤儿。
- 编辑保存 → 下游已确认拍标 stale → 对话框三选一：仅替换 / 替换并重跑后续 / 开新分支（默认）。
- 开新分支保留旧分支可读；正文 header 显示分支名与 revision。

**自动模式**

- 开关在预览 header；开启前预检：将连续生成 N 拍、预估 token / 费用、拍数上限、预算上限。
- 运行中：确认条变为 `自动运行 · 12/24` + [暂停]；暂停原因在状态栏与拍卡同时显示。
- 暂停条件：出口满足 / 预算 / max_beats / 拒演 / 分镜耗尽 / 模型错误；任一触发即停，不即兴续写。
- 分镜耗尽：场景关闭 + `storyboard_exhausted` 横幅 + [补分镜]。

**分镜 tab**

- 表：场次 / 拍号 / speaker / intent / 字数上限 / 出口条件；行可拖排序。
- 冲突行内联：speaker 不在场、intent 与角色卡矛盾、出口条件不可判定（红点 + 文案）。
- `notes` 字段标「不进任何 Agent 上下文」，输入框旁固定说明。
- 开演按钮在 header：冲突 0 才可用；点击弹 G2 确认（场次数、拍数、预估）。

**章节完成**

- 所有场景 closed → 状态栏「草稿完成」+ 预览 header [送审]；点击进入审批台并生成报告。

### 5.5 文件树区

- 稿件 / 分镜 / 蓝图 / 角色 / 导出 + 数据库视图；当前文件高亮。
- 分镜文件显示版本 v2；草稿与定稿用不同徽标。
- 右键：在资源管理器中显示、复制路径、查看历史。

### 5.6 状态、键盘与不做

|---|---|---|

| 开演中 | 拍内光标 + 耗时 | 停止 |
| 等待确认 | 确认条高亮 | 确认 / 重生成 / 编辑 |
| 自动运行 | 预览 header 运行态 + 暂停 | 暂停 |
| 暂停 | 原因横幅 | 继续 / 改分镜 |
| 草稿完成 | 送审 CTA | 送审 |

## 6 审批台

### 6.1 布局

- 与创作台同构；预览默认「报告」，进入时报告已生成。
- 报告未生成时显示骨架 + 生成按钮（G4）。

### 6.2 会话列表区

- 待审批（draft_complete）/ 历史 / 修订轮次。
- 轮次：R1 报告 → R1 修订 → 复检 → R2 … 最多 3 轮；超限显示「转人工」。
- 历史行：章节 + 轮次 + 结论 + 时间；点击载入当时的报告与 diff（只读）。

### 6.3 对话聊天区

- 报告摘要卡：结论、阻断数、建议数、[打开报告]。
- 讨论阶段不改稿：任何「改这里」的输入，Agent 只能产出建议或 patch 提案，需 G5 授权。
- 证据引用：memory / outline chips；私有记忆只显示 ID + 最小必要证据，不整段复制。
- [授权修订 G5] 固定在底部；点击后进入 patch 生成，作者逐条接受。

### 6.4 文件预览区与 G6

Tabs：初稿 / 报告 / 差异 / 版本。

**初稿**

- 只读正文；gutter 显示 issue 标记（阻断实心、建议空心），点标记打开 issue 卡并联动报告。
- 不在初稿里直接改字：修订只走差异 tab 的 patch；初稿始终对应一个 revision。

**报告**

| 区域 | 内容 | 交互 |
|---|---|---|
| 结论 | pass / pass_with_notes / fail | 顶部横幅；fail 显示阻断数 |
| 维度 | 人物一致性、剧情逻辑、纲要对齐、文笔 | 1–5 分 + 评分标准 tooltip；只看趋势 |
| 阻断项 | 类型、beat、证据原文、为什么、建议 | [定位] [加入修订] |
| 建议项 | 类型、beat、说明 | [定位]；默认折叠 |

- 每条问题必须有 `issue_id`、beat 定位与证据；没有证据的条目降级为建议，不进阻断。
- 报告不显示私有记忆全文；引用 ID 与必要片段。

**差异**

- 三视图：并排 / 内联 / 仅问题；默认内联。
- 每个 hunk 一个 patch 卡：before / after、reason、issue_ref、[接受] [拒绝]。
- 拒绝保留原文；接受写草稿区并生成新 revision；只复检受影响维度。
- 未变更段落折叠；行号与 beat 双锚。

**版本**

- revision 列表：id、kind（draft / final）、parent、hash、时间、作者；点击对比任意两版。
- 定稿只读，不能在此回退；回退走「重新打开」生成新 revision。

**G6 定稿**

- 按钮只在预览 header 右侧，审批台之外没有；无快捷键。
- 有阻断时禁用并显示第一条；有未复检改动时对话框列出清单，要求勾选「我已复核」。
- 定稿 → 冻结快照 → 触发记忆固化任务 → 跳记忆台。
- 3 轮超限仍可定稿，但显示「已转人工，保留全部报告与 patch」。

### 6.5 文件树区

- 纲要 / 角色 / 世界 / 章节 + 数据库视图（审批报告、角色记忆）；审批中所有文件只读。
- 点纲要跳到对应章纲；点角色卡跳到 voice 字段（审批对照用）。

### 6.6 状态、键盘与不做

| 状态 | 表现 | 动作 |
|---|---|---|
| 无待审 | 空态 + 去创作台 | 继续写作 |
| 报告生成中 | 骨架 + 停止 | 停止后保留部分报告 |
| schema 降级 | 纯文本报告 + 阻断项仍需定位 | 重试结构化 |
| 复检中 | patch 卡进度 | 等待 |
| 3 轮超限 | 转人工横幅 | 定稿或人工处理 |
| 只读锁 | 横幅 + 禁用 | 浏览 |
| 离线 | 审批禁用 | 看历史 |

| 快捷键 | 动作 |
|---|---|
| Ctrl Enter | 发送 |
| N / P | 下一 / 上一问题 |
| A / X | 接受 / 拒绝选中 patch |
| D | 打开差异 |

- 不做：改定稿 / 设定 / 记忆；补写新情节；给「定稿」加快捷键；跳过 G6 自动定稿。

## 7 记忆台

### 7.1 布局

- 预览默认「提案」；进入时定位到最新 proposed 任务。
- 无待处理任务时显示「下一章定稿后，这里会出现固化提案」。

### 7.2 会话列表区

- 待处理（proposed / awaiting_confirm）、历史固化（applied / superseded）、维护（重建、归档 P2 未开放）。
- 行显示章节、revision、条目数、job 状态。

### 7.3 对话聊天区

- 摘要卡：新增 / supersede / 关系 / 世界事实计数。
- 逐条追问：来源、为什么重要、与哪条冲突；回答引用章节 / 拍。

### 7.4 文件预览区

Tabs：提案 / 角色记忆 / 世界状态 / 关系图 / 审计。

**提案**

- 分组：角色（新增 / supersede / 关系）、世界事实。
- 每条：kind、text、source（chapter / beat）、importance、pin、[接受] [编辑] [拒绝]。
- 「应用」只写已接受条目：写向量库（带 `source_revision`）+ 更新世界状态与关系图；`job_id` 幂等；失败保留原状态并可重试。
- 台词不是事实：belief 条目标「角色以为」，不提供「转为事实」快捷按钮（需作者在世界状态里显式新增）。

**角色记忆**

- 过滤：角色、类型（经历 / 事实 / 关系 / 认知）、章节、状态（active / inactive / superseded）、pin。
- 列表列：文本、来源、learned_seq、有效期、重要度、状态。
- 详情抽屉：原文、来源引用、审计链、[标记错误] [按章重建]。
- 不物理删除；失效用软状态。

**世界状态**

- as-of 控件：章 + seq 滑杆；默认「当前章结束」。
- 事实表：subject / predicate / object / truth / visibility / known_by / reveal_seq / valid_from–to。
- 角色信念单独一节：「角色以为什么」，可与事实矛盾。
- 旁白视角预览：切到「读者已知」看 reveal_seq 过滤后的结果。

**关系图**

- 节点 = 角色，边 = 信任 / 亲密 / 张力；时间轴回放；点边看来源事件。
- 边宽 = 强度，虚线 = 单向未确认；不显示私有记忆文本。

**审计**

- 每条记忆的来源章节 / revision / 拍；可按章重建（确认后旧条目 inactive）。
- 标记错误 → 失效并记录原因；不删除。
- 工具调用记录：tool、版本、耗时、degraded、错误码；不显示 args 原文（PRD §4.9.7）。

### 7.5 文件树区

- 角色卡 / 世界规则 / 记忆视图 / 世界状态视图 / 关系图视图；文件与数据库视图分开。
- 角色卡与记忆视图分开：卡是设定，记忆是经历。

### 7.6 状态、键盘与不做

| 状态 | 表现 | 动作 |
|---|---|---|
| 无待处理 | 空态 | 等下一章定稿 |
| 提案生成中 | 进度 + 停止 | 停止保留部分 |
| 生成失败 | job failed | 重试 |
| 应用进行中 | 进度 + 取消 | 等待 / 取消 |
| 离线 | 抽取禁用；应用可用 | 应用已生成提案 |
| 只读锁 | 横幅 + 禁用 | 浏览 |

| 快捷键 | 动作 |
|---|---|
| J / K | 下一条 / 上一条 |
| A | 接受当前条目 |
| X | 拒绝当前条目 |
| E | 编辑当前条目 |

- 不做：改正文；读初稿；物理删除；自动归档事实 / 承诺 / 伏笔 / 身份。

## 8 设置中心

### 8.1 窗口与布局

- 独立窗口 1040×720（最小 880×600）；左导航 220；内容最大 680；header 54（面包屑「设置 / 分类」+ 页面标题）；状态行 26。
- 分组一律用卡片：8px 圆角、1px 边框、16px 内边距；分组标题 11.5/600；卡片内行间 1px 细分割线；保存反馈统一在 header 右侧。
- 独立窗口意味着主窗口可以继续写作；设置改动即时生效，除语言与数据目录需重启。

### 8.2 分类与配置项

| 分类 | 包含 | 关键约束 |
|---|---|---|
| 常规 | 语言、启动行为、默认项目目录、更新通道、自动更新 | 语言 / 目录需重启；更新失败不阻塞启动 |
| 外观 | 主题、强调色、正文字体 / 字号 / 行距、密度 | 切换即预览；5 秒内可撤销 |
| Agent 管理 | 6 个 Agent + 角色实例的绑定、temperature、max tokens | 显示继承链；下一拍生效 |
| 提供方 | OpenAI / DeepSeek / 通义、Key、base URL、测试连接、模型与计价 | Key 只存 safeStorage；不再明文回显 |
| 记忆与上下文 | top_k 档位、上下文预算、压缩顺序、章末摘要、嵌入模型 | 嵌入模型只读；换模型需重建索引 |
| 安全与权限 | 项目锁、审计导出、Key 存储说明、危险操作确认 | 不提供「关闭项目锁」 |
| 通知 | 4 类事件 × 系统 / 应用内、勿扰时段 | 窗口聚焦时不发系统通知 |
| 快捷键 | 全局 / 页面分组、冲突检测、重置 | 定稿不提供可绑定项 |
| 高级设置 | 日志级别、数据目录、重建索引、完整性检查、schema、实验开关 | 实验项标注里程碑；需确认 |

### 8.3 外观与主题卡

- 主题卡 3 张：明亮 / 暗色 / 跟随系统；每张最大 220×96：迷你窗口预览 + 名称 + 一句描述 + 选中环。
- 预览用真实组件渲染（mini window），不用截图；切换立即应用到整个应用。
- 强调色 5 个预设 + 自定义；只改 accent，不改语义色。
- 正文字号 3 档（小 14 / 标准 15 / 大 16），行距 1.6 / 1.8 / 2.0；预览区即时变化，导出不受影响。

### 8.4 提供方与逐 Agent 绑定

- 提供方卡：名称、状态（已连接 / 未测试 / 失败）、Key（末 4 位）、[测试连接]、模型表（上下文长度、价格）、启用开关。
- 测试连接返回延迟与首个可用模型；失败给错误码与「检查 Key / 代理 / 区域」。
- 绑定表：Agent / 当前绑定 / 继承来源 / temperature / 最近使用；角色行可展开到实例。
- 继承链：`character:<id>` → `character` → 项目默认；其他 Agent 直接继承项目默认。
- 改绑定提示「只影响下一拍；正在生成的任务不换模型」；保存后写审计，可回滚上一套。

### 8.5 状态、键盘与不做

| 状态 | 表现 | 动作 |
|---|---|---|
| 已保存 | header「已保存」 | — |
| 保存中 | 细进度条 | — |
| 保存失败 | 红色横幅 | 重试 |
| 测试中 | 按钮转圈 | 取消 |
| 测试失败 | 错误码 + 建议 | 重试 / 改 Key |
| 未绑定 | 行内「继承项目默认」 | 绑定 |
| 需重启 | 徽标 + 提示 | 稍后重启 |

| 快捷键 | 动作 |
|---|---|
| Ctrl , | 打开设置 |
| Ctrl F | 搜索设置项 |
| Esc | 关闭窗口 |

- 不做：在设置里管理项目内容；显示完整 Key；生成中切模型；绑定未通过测试的模型。

## 9 全局组件与交互契约

### 9.1 闸门行动条

| 闸门 | 位置 | 主操作 | 禁用条件 |
|---|---|---|---|
| G0 | 新建向导 | 创建 | 校验未过 |
| G1 | 规划台预览底部 | 确认蓝图 | 覆盖检查有阻断 |
| G2 | 创作台分镜 header | 开演 | 分镜冲突 |
| G3 | 创作台确认条 | 确认 | 当前拍未落草稿 |
| G4 | 审批台报告 header | 生成报告 | 章节未 draft_complete |
| G5 | 审批台底部 | 授权修订 | 无报告 / 轮次超限 |
| G6 | 审批台预览 header | 定稿 | 有阻断 / 未勾选复核 |
| G7 | 记忆台底部 | 应用 | 无已接受条目 / applying |

- 闸门按钮文案用动词，不用「确定」；旁边永远显示阻塞原因或条目计数。
- 闸门动作写 `gate_record`：按钮点击后先落审计再执行。
- 每个闸门只有一个主按钮；次级动作（影响预览、逐条查看、全部接受）不得使用主按钮样式。

### 9.2 拍卡与流式状态

| 状态 | 徽标 | 可用动作 |
|---|---|---|
| proposed | 待生成 | 生成 |
| generating | 生成中 + 光标 | 停止 |
| draft | 待确认 | 确认 / 重生成 / 编辑 |
| confirmed | 已确认 | 查看依据 |
| stale | 虚线「上游已改」 | 重跑范围三选一 |
| superseded | 灰「旧版本」 | 查看 / 对比 |
| author_edited | 「已手改」 | 对比 / 重跑 |
| rejected | 灰「已拒绝」 | 重新生成 |

- 流式只在拍内增长，不改变其他拍位置；停止后保留已生成文本并标 draft。
- 气泡内不显示 token 流式计数；只在拍头显示耗时，避免作者盯着成本写作。

### 9.3 Diff 与 patch

- 三视图；hunk 级接受 / 拒绝；未变更折叠；行号 + beat 双锚。
- patch 卡片含 reason 与 issue_ref；拒绝不删除 patch 记录。
- 复检只跑受影响维度，结果贴在 patch 卡下方。

### 9.4 依据 chips

- 类型：memory / belief / fact / outline / beat；不用颜色区分类型，用前缀与图标。
- hover 显示摘要与来源；点击打开依据面板；私有记忆原文需再点一次「查看原文」（审计）。
- chips 不是事实证明；面板顶部固定这句说明（PRD 4.6）。

### 9.5 任务卡与错误

- 任务卡：类型、状态、进度、取消 / 重试、错误码。
- 错误码到文案：model_error（模型超时，可重试）、memory_empty（没有可用记忆）、context_trimmed（上下文已裁剪）、storyboard_conflict（分镜冲突）、character_refusal（角色拒演）、storyboard_exhausted（分镜耗尽）、file_conflict（文件被外部修改）、human_takeover（转人工）。
- 行内错误优先于 toast，toast 优先于对话框：能就地解决的不要弹窗。

### 9.6 通知

- 4 类：生成完成、需要确认、失败、预算超限。
- 只在窗口失焦时发系统通知；点击聚焦到拍 / 章节 / 任务。
- 不通知每个 token；自动模式只通知暂停与完成。

### 9.7 快捷键总表

| 快捷键 | 范围 | 动作 |
|---|---|---|
| Ctrl K | 全局 | 命令面板 |
| Ctrl N | 全局 | 新建项目 |

| Space | 创作台 | 自动模式暂停 / 继续 |
| Ctrl Shift C | 创作台 | 上下文检查器 |

### 9.8 文案与数字格式

- 字数千分位；token 千分位；金额 ¥ 两位小数；时间 ≤7 天用相对，否则日期。
- beat 显示 `bt_012`，revision 显示 `rev_012`，job 显示 `job mem_003`。
- 空态公式：一句解释 + 一个主操作 + 一个可选链接；不写「暂无数据」。
- 禁用态必须有原因，不写「不可用」。
